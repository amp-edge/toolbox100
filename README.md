# ToolBox 100
A static, dependency-free website containing 100 free online tool pages.

## Run
Open `index.html` in a browser or upload the entire folder to any static host.

## Customize
- Change branding in `index.html` and tool templates.
- Edit `assets/style.css` for design.
- Add richer calculations to `assets/tools.js`.
- Add privacy, terms, contact, and affiliate pages before production monetization.

## Important
Health and financial calculators are educational estimates and should include suitable disclaimers before production use.
